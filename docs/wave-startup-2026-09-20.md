# 波浪启动遮罩（2026-09-20）

按启动体验反馈，将启动页的两段透明度淡出替换为自上而下的波浪揭幕：

- 380 ms 单一动画，使用 FastOutSlowIn 曲线，不增加固定等待。
- 曲线以上直接显示已布局的主界面，以下保留完全不透明的启动页，Logo、标题、页脚与背景一起裁切。
- 路径复用，通过 Canvas.clipPath 硬件裁切；不逐帧截图、不创建全屏位图。
- 保留首帧提交、窗口焦点及 Android 12+ 系统 splash 交接条件；页面销毁取消动画并移除监听。
- 系统关闭动画时由 ValueAnimator 直接结束并移除遮罩。
- 保留关闭应用启动页时的既有行为。

参考核对：本次读取 MikuRay 公开仓库的 SplashActivity，当前源码为延时加淡入淡出，并非反馈中描述的波浪动画。本实现遵循反馈指定的波浪效果，不声称复用了上游波浪实现。
