# MikuBox 后续修复与验证 · 2026-09-20

## Mixed / System 直连故障

旧实现把 MikuBox 自己的整个 UID 排除在 VPN 之外。Mixed/System 的内核 TCP listener 同属该 UID，其返回包也被绕开 TUN，导致规则正确匹配却无法建立 TCP 连接。gVisor 的用户态 TCP 路径没有同样的问题。

修复后不再豁免整个应用 UID；在 Mihomo 真正拨出的 socket 上经 Go/JNI 调用 VpnService.protect，并绑定 NOT_VPN 的物理网络。内部 TUN listener 不使用这个出站 hook。按应用白名单仍包含自身 UID。网络切换监听更新底层网络和系统 DNS；服务停止按所属实例清理，避免旧服务清掉新服务的桥接状态。

另修复 Android 系统 DNS resolver 的并发读写；DNS 覆写采用递归合并，保留用户配置中未覆写的 fallback-filter 子字段。
