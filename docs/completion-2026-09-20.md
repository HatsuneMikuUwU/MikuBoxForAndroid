# 剩余功能收尾 · 2026-09-20

## 脚本库与按配置绑定

入口保持在进阶设置的“配置覆写脚本”分类，新增“脚本库”和“按配置绑定脚本”。

- 脚本库支持新建、编辑、重命名、删除、预览与校验保存。名称不可重复，绑定使用稳定 ID，重命名不丢绑定。
- 每个配置可选专用脚本、继承全局脚本或禁用脚本。专用脚本独立于全局开关；继承全局才受全局开关控制。原有全局脚本无需迁移。
- 删除被绑定的脚本会把对应配置改为禁用脚本，不会偷偷改用全局脚本。删除配置时清除其绑定。
- 编辑被绑定的脚本时，预览使用它绑定的配置，并明确展示预览配置名。
- 只在当前配置的有效脚本改变时重载连接；修改未被当前配置使用的脚本不重启 VPN。
- VPN 与仅代理服务都根据本次加载的配置 ID 取脚本，避免异步加载期间选择变化造成串用。
- 脚本库、绑定作为一个 JSON 文档原子保存，沿用已有备份存储。导入前校验库结构及引用；损坏文档不会导致部分备份先写入。
- 订阅内容更新不改变脚本绑定，也不把脚本结果覆盖回订阅源。

相关依赖的许可证已随 APK 打包。

## 运行中发现并修复的问题

- 开机连接不再借用交互式启动路径。未获 VPN 授权时不从后台拉起授权页，也不错误地停留在“连接中”；按需连接会显示需完成配置/授权的通知。
- 快捷开关断开再连接时复现了“显示已连接、实际 TUN 消失”。Mihomo 的 `executor.Shutdown()` 关闭设备却保留 `LastTunConf`；Android 复用同一个 fd 时，`ReCreateTun` 误判配置相同而跳过创建。停止时现先通过 `ReCreateTun(Tun{})` 清除该缓存。
- 增加 Go 回归测试防止保留旧 TUN 配置；设备测试连续三次重连，每次从独立测试应用 UID 验证 DIRECT 和必须经过 HTTP 代理的流量。日志确认 fd=92 连续复用时仍重新创建 TUN。
