# 订阅导入首次拉取修复（2026-09-20）

## 原因与改动

订阅编辑页原先只保存地址，首次下载依赖开启自动更新后 WorkManager 的第一次执行；`clash://`、`sn://` 导入也存在只创建空配置的问题。

- 保存新增订阅、尚未成功下载的订阅或变更地址时，后台立即下载配置，与自动更新开关独立。
- 下载成功后关闭编辑页并同步节点；失败保留条目并提示重新保存重试，复用同一个 ID。
- 更换地址后重置下载时间，保留旧配置直至替换成功，失败后仍可重试。
- HTTP(S)、Clash、SN 导入入口统一执行首次下载，失败不会被报告为成功。
- 修正编辑页“通过代理更新”的错误文案；更新间隔按界面标示的分钟保存与回显。
- 新订阅明确显示自动更新、代理更新均禁用的默认状态。
