# MikuBox v0.2.1

- 配置组支持删除：在首页“+ → 管理配置组”或长按组标签操作。删除后组内配置和订阅移回 Miku，保留内容、更新设置和选中状态；默认 Miku 组不能删除。首页同步刷新列表和计数。
- 配置编辑器改用分区卡片、图标、字段摘要和紧凑编辑行，与现有 Material 3 主题保持一致。可视化与完整 YAML 可直接切换；节点、策略和规则支持明确的更多操作入口，基础运行模式使用选项列表。
- 修复首次订阅开启“通过代理更新”时无法初始化：优先使用已连接的代理；尚无配置且未连接时先直连下载。代理偏好仍保留，已有配置的后续更新不会自动绕过该设置。首次失败可继续重试。

可视化修改会重新排版 YAML 并移除注释，编辑器中已有提示。首次直连仍需要订阅地址能通过当前网络访问。

验证：55 项 JVM 回归、Lint（0 错误）、Android 16 arm64 模拟器分组删除/数据保留/首次订阅下载，以及编辑器浅色、深色、草稿恢复和 YAML 切换。
