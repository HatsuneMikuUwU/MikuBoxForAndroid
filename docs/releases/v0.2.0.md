# MikuBox v0.2.0

## 更新

- 主页与通知共用出口 IP 快照；切换出口时丢弃过期结果，避免重复启动通知刷新任务。
- VPN 前台服务启动失败时停止建立隧道；手动断开及权限撤销清除恢复意图。VPN 设置提供系统始终开启和电池优化入口，无需锁定最近任务。
- 路由设置按配置文件、目标策略显示开关。覆盖项独立保存，订阅刷新保留选择，原始规则不被删除；关闭规则后无匹配流量直连，可手动应用到当前连接。
- 支持创建配置组、导入到当前组，以及在配置和订阅编辑页选择分组。配置归属持久化，并随备份恢复。
- 配置编辑默认显示完整 YAML 解析树，支持字段、布尔开关、列表增删和排序。保留整份原始 YAML 编辑入口及未保存草稿的旋转恢复。可视化修改保留未知字段，但会重新排版并移除注释，界面会提示。
- 设置分类图标与背景改用 Material 3 语义颜色，跟随浅色、深色及动态主题。
- 固定支持 Kotlin 2.4 元数据的 D8/R8 版本，消除旧打包器的元数据处理告警。

## 后台运行说明

Android 前台 VPN 服务、系统始终开启 VPN 与电池优化豁免可提高连接可靠性，但系统强制停止、撤销 VPN 授权以及部分厂商限制仍可能中断连接。应用不会尝试抵消用户明确的断开或权限撤销操作。

## 验证

52 项 JVM 回归、Go bridge 测试、三种 ABI 构建及 Android 16 arm64 模拟器网络/分组/路由/快捷操作测试通过。已实测后台普通清理保活、意外进程退出恢复和主动断开。Lint 为 0 错误、248 警告；实体设备厂商省电策略尚未覆盖。详见仓库中的 `docs/releases/v0.2.0-verification.md`。
